# Virena Design Lab

Витрина компонентов и прототип авторизации для разработки.

- Витрина: https://petrpetryaev.github.io/virena-design-lab/
- Каталог и флоу используют общие React-компоненты. Есть светлая, тёмная и системная темы.
- Авторизация, Google, отправка писем и ответы сервера имитируются. Тестовый код: `123456`.
- Данные прототипа сохраняются в текущем браузере. Не используйте реальные пароли.

## Запуск

Node.js 22+ и npm:

```sh
npm ci
npm run dev
```

Открыть http://localhost:5174/. `npm run build` создаёт `dist`.

## Структура

`src` – компоненты и флоу, `public/snapshot.json` – исходный снимок дизайна, `public/assets` – локальные изображения/векторы. Внутренние ключи Boris сохранены для связей снимка, видимые названия – Virena.

Дата: React Aria DateField + React DayPicker. Телефон: libphonenumber-js и локальный форматтер.

## Публикация

GitHub Actions собирает и публикует main в GitHub Pages. Для сборки в подпапке устанавливается `DEPLOY_BASE=/virena-design-lab/`. Исходники и ресурсы публикуются вместе.

## Границы передачи

Это прототип, не готовая серверная авторизация. Нужны API/OAuth, утверждённые тексты документов, продуктовые справочники стран/городов и поддержка. Полная адаптивность и все состояния исходных статических вариантов ещё не приняты. Локальные правки не синхронизированы в Figma. Компоненты на витрине и старые варианты снимка могут различаться.

Проверены адресные сценарии ввода даты, телефона, Select, поиска, загрузки, сетевых ошибок и основных демонстраций каталога; это не полное покрытие продукта.
