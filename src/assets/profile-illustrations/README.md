## Theme integration
These JPEGs are not transparent. CSS uses multiply for light surfaces and inverted screen for dark surfaces, preserving the same silhouette without separate theme generations. Do not isolate the blending wrapper from the parent card's background. Both images are decorative with empty alt text and aria-hidden on their wrapper.
