# Область готовности прототипа

Витрина содержит каталог компонентов, демонстрационный флоу авторизации и кабинет с экраном «Обзор» для семи состояний участника: новичок, клиент, партнёр без пакета, партнёр с пакетом, льготное окно, заморозка и деактивация.

## Общие карточки

`src/cabinet/components/Cards.jsx` используется экраном и каталогом: Media card (продукт/партнёрство), Banner card (пакет/7 дней), Profile card, Sponsor card. В каталоге доступны белый/мягкий фон; у всех карточек – загрузка, у профиля и спонсора также ошибка и повтор. Скелетоны сохраняют геометрию карточек. Темы светлая/тёмная.

## Ограничения

Это интерактивный прототип: нет API, платежей или реальных персональных данных. Имя, ID, цены и даты – демонстрационные данные. Кольца у 7 дней и 2 дней льготного окна декоративные, не связаны с серверным временем. Переходы ведут в заглушки целевых разделов.

Основной состав «Обзора» новичка соответствует экранному ТЗ: профиль, спонсор, предупреждение о 7 днях, активность, продукты и пакет. Это не завершение всей TES-341: состояния участника представлены демо-данными; персональный спонсор, реальные действия и полная мобильная спецификация не реализованы. Свежие изменения не синхронизированы с Figma.

## Отличия от экранного ТЗ

По визуальным итерациям: уведомление с синим акцентом над профилем вместо оранжевого; заголовок страницы вместо приветствия и языка; ранг показан медалью/«Пока нет» вместо звёзд/«Ранга нет». Счётчик вынесен из профиля в уведомление; пакет пока не интерактивный чип. Нет нижней мобильной панели действий и времени МСК в подвале. Тексты карточек требуют продуктового согласования. Эти различия следует решить до production, не считать окончательно согласованным ТЗ.


## Обновление 03.11.2026

Компактная сводка финансов, бинара, годового бонуса и команды. Карточки с доступным действием кликабельны целиком, кнопки доступны с клавиатуры. ID копируется общей кнопкой, результат показывается тостом. При раскрытии группы меню открывается первый раздел. В заморозке показатели серые, уведомление со снежинкой. Во всех карточках партнёрства используется коллаж с лицами.

## Приглашения и общий каталог участников · 05.11.2026

Добавлен прототип личных приглашений: этапы, поиск/фильтры, контакты, заметки и демонстрационные напоминания. Участники и приглашения используют один MemberTable/DataTable, общие статусы, пакеты и бейдж «Вы». Drawer, меню действий, поиск и пагинация имеют единое поведение; поддержан reduced motion. Баннеры соответствуют вариантам Обзора.

Перед новым UI-компонентом проверять существующие применения и переиспользовать реализацию. Иконки берутся из Figma-библиотеки Solar; происхождение экспорта хранится в src/assets/directory-icons/sources.json. Не рисовать похожие иконки вручную. Сортировка показывает активную стрелку и серую подсказку при наведении. Недоступные действия скрыты из меню. Обновление массива данных при открытии drawer не должно запускать анимацию строк.

Данные вымышлены; настоящая отправка писем, API и платежи не подключены. Девять вкладок из спецификации сохранены; упрощение до двух вкладок пока только предложение.

### Бизнес-центр · Новости · TES-346

Открыть [ленту](http://localhost:5174/?tab=cabinet&page=news). В настройках витрины выбрать «Состояние новостей». Состояние также задаётся параметром `newsScenario`. Для проверки открытой новости добавить `intent=article:partner-cabinet-guide`.

| Ситуация | Как проверить | Поведение |
| --- | --- | --- |
| Первый вход или медленный ответ | `loading` в ленте и статье | Скелетон и доступное название загрузки. В статье доступен возврат. До получения статьи отметка о прочтении сохраняет прежнее значение. |
| Ошибка запроса | `error` | Сообщение об ошибке и «Повторить». При повторе видна загрузка, затем содержимое того же экрана. |
| Публикаций нет | `empty` | Пустое состояние без поиска и пагинации. |
| Одна публикация | `single` | Только одна карточка. В статье скрыта подборка других новостей. В фильтре доступны только категории с публикациями. |
| Фильтрация | Выбрать категорию, ввести от трёх символов | Поиск работает в выбранной категории по заголовку, описанию и тексту. Для пустой выдачи доступен сброс. |
| Следующая страница | В обычной ленте нажать «Показать ещё» | Вначале 12 публикаций. Во время загрузки повторное нажатие недоступно. В конце списка кнопка исчезает. |
| Следующая страница недоступна | `more-error`, затем «Показать ещё» | Строки остаются на месте. Ошибка и повтор появляются внизу списка. Повтор добавляет оставшиеся публикации. |
| Прочитано / непрочитано | Открыть статью и вернуться, затем проверить `all-read` | Меняются бейдж и счётчик. Когда всё прочитано, действие массовой отметки скрыто. |
| Ошибка массовой отметки | `read-error`, выбрать действие в меню ленты | Бейджи сохраняются, появляется сообщение с повтором. После успешного повтора отметки обновляются. |
| Удалённая или неопубликованная статья | `intent=article:missing` | «Новость не найдена» с возвратом в ленту. Будущие публикации исключаются также из списка и рекомендаций. |
| Нет обложки / ошибка изображения | `no-cover` | Используется обложка категории. При недоступности обоих изображений материал остаётся доступен для чтения. |
| Перевод отсутствует | `russian-only` в статье | Показан русский текст и пояснение о языке. |
| Богатое содержимое | Статьи `partner-cabinet-guide` и `catalog-update` | Проверить заголовки, таблицу, ссылку внутри абзаца, дополнительное фото с подписью, переход назад. |

**Граница реализации.** В витрине тексты берутся из локального набора, ошибки и задержки воспроизводимы, отметки хранятся в sessionStorage текущей вкладки. При подключении CMS сервер отвечает за доступ и время публикации, локализацию, страницы выдачи и хранение прочитанного для текущего пользователя. Успешное чтение статьи и подтверждённая массовая отметка должны обновлять счётчик. Ошибка одного запроса не должна очищать ранее загруженные страницы.

### Бизнес-центр · Список акций · TES-417

[Открыть список](http://localhost:5174/?tab=cabinet&page=offers). Пункт «Акции» расположен под «Моими покупками». Сортировка и правила участия описаны в [ТЗ раздела](https://linear.app/teslavita/document/tz-pokupki-dejstvuyushie-akcii-biznes-centr-virena-8d4769c90837).

| Что проверить | Как воспроизвести | Ожидаемый результат |
| --- | --- | --- |
| Сроки и сортировка | Пройти «Действующие», «Скоро», «Архив» | Внутри каждой группы действующие закреплённые идут первыми, затем более новые. Предстоящие идут от ближайшей даты, завершённые от недавней. День окончания включён по Москве. |
| Условия | Открыть недоступную акцию, затем выбрать состояние «Условия выполнены» | Оформление баннера сохраняется, показаны причины. Когда одновременно выполнены требования к стране, звёздам и покупке, акция входит в доступную группу. |
| Все недоступны | Выбрать состояние «Все акции недоступны», выключить показ недоступных | Скрываются карточки и счётчик. Включение переключателя возвращает акцию. Настройка общая для трёх вкладок. |
| Счётчик | Открыть действующую акцию и вернуться; отдельно выбрать «Все просмотрены» или «Больше девяти новых» | Просмотр списка сохраняет статус «Новая». Открытие акции обновляет меню и вкладку. При нуле бейдж скрывается, десять и более обозначаются «9+». |
| Загрузка и ошибка | Выбрать одноимённые состояния в настройках витрины | Загрузка имеет доступное название. Повтор после ошибки возвращает содержимое. |
| Пусто | Выбрать «Нет акций», пройти три вкладки | Каждая вкладка объясняет отсутствие акций для своего периода. |
| Следующая страница | Открыть архив, нажать «Показать ещё»; повторить в состоянии «Ошибка дозагрузки архива» | Первая порция содержит до десяти акций. При ошибке строки остаются на месте, повтор добавляет оставшиеся. |
| Нет баннера или перевода | Выбрать «Без баннера» либо «Перевод отсутствует» | Карточка сохраняет пропорции, открывается и читается. Если у предложения отсутствует перевод, возвращается русская версия. |
| Прямой вход | Открыть `intent=offer:expert-week`, затем неизвестный идентификатор | По существующему ID открываются сведения, для отсутствующего есть возврат к списку. |

Сценарии выбираются в настройках или через параметр `offersScenario`. Список использует локальные примеры с относительными сроками. Страна берётся из профиля, звёзды из данных кабинета, список покупок из истории оформленных заказов за вычетом возвратов. Для подключения сервера понадобятся опубликованные акции с постоянными датами, локализованные материалы и настройки доступности. Просмотры и видимость недоступных сейчас хранятся в этом браузере под ID партнёра. Для переноса между устройствами нужны настройки на стороне аккаунта. Полные условия, вложения и публичная страница с реферальной ссылкой относятся к отдельным задачам.

## Ревью Бизнес-центра и общих компонентов

В ветке `review/tes-342-invitations` общие правые панели и обновлённые экраны доступны в одной сборке. Для выбора состояний добавьте `lab=1` к адресу.

| Задача | Прямой маршрут |
| --- | --- |
| TES-337 · Каркас Бизнес-центра | `?tab=cabinet&page=overview&member=partner` |
| TES-339 · Профиль | `?tab=cabinet&page=profile` |
| TES-342 · Личные приглашения | `?tab=cabinet&page=invitations` |
| TES-343 · Финансы | `?tab=cabinet&page=finances` |
| TES-343 · История | `?tab=cabinet&page=finances&financeView=history` |
| TES-456 · Каталог компонентов | `?tab=components` |
| TES-456 · Вход | `?tab=flows&screen=login` |

Контейнер правой панели находится в `src/cabinet/components/CabinetDialog.jsx`; карточка участника из списка и дерева использует `ParticipantDetails.jsx`. Шапка кабинета и часы используют `src/CabinetShell.jsx`. Часы отображают время из HTTP-заголовка Date и показывают прочерк при недоступности ответа. Источники данных профиля, финансов, приглашений и заказов в сборке — локальные фикстуры. Отправка кодов, смена паролей, вывод средств и удаление учётной записи требуют подключения сервисов Бизнес-центра.
